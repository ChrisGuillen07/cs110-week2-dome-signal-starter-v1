# Kairova Dome Signal

A CS110 Week 2 website project for the Kairova dome signal.

## Features

* Displays a visible Hello, World heading
* Identifies the Kairova dome
* Shows the dome's online status
* Includes a signal confirmation button
* Provides an instruction for the next crew
* Uses responsive HTML and CSS for desktop and phone widths

## Testing

The website was tested in a web browser. The signal button changes the dome status when pressed.
